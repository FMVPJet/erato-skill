# Rhyme Guide (押韵参考)

## 普通话：十三辙

中文歌词押韵以韵母为基础。十三辙是传统分类，覆盖所有普通话韵母：

| 辙名 | 韵母 | 例字 |
|---|---|---|
| 发花 | a, ia, ua | 花/家/他/下/大 |
| 梭波 | o, uo, e | 歌/河/说/过/落 |
| 乜斜 | ie, üe | 夜/别/雪/月/切 |
| 姑苏 | u | 路/哭/住/雾/孤 |
| 衣期 | i, ü, er | 你/去/雨/离/地 |
| 怀来 | ai, uai | 来/爱/海/外/白 |
| 灰堆 | ei, ui(uei) | 泪/回/美/飞/醉 |
| 遥条 | ao, iao | 好/笑/老/少/飘 |
| 由求 | ou, iu(iou) | 走/手/头/流/久 |
| 言前 | an, ian, uan, üan | 天/年/远/眼/暖 |
| 人辰 | en, in, un, ün | 人/心/门/深/真 |
| 江阳 | ang, iang, uang | 光/想/忘/长/伤 |
| 中东 | eng, ing, ong, iong | 风/梦/等/情/空 |

## 押韵策略

### 密度选择

| 场景 | 建议 |
|---|---|
| 副歌 | 密押（每行或隔行），增强记忆感 |
| 主歌 | 松押（隔行或更松），给叙事留空间 |
| Bridge | 可以转韵，制造对比 |
| 粤语歌 | 整体偏密，尤其副歌 |

### 韵母的情感色彩（普通话）

Different rhyme families have different emotional qualities. Choose rhymes that match the emotional intensity of each section.

#### 开阔韵（适合副歌、释放、呐喊）

**江阳韵** (ang/iang/uang): 光/想/忘/长/伤  
→ 最开阔，最适合大情绪爆发  
→ 适合：副歌高潮、呐喊、释放  
→ 例：《光年之外》"想/忘/光"

**发花韵** (a/ia/ua): 他/下/大/家/花  
→ 明亮、直接、有力  
→ 适合：坚定的情感、决绝的态度  
→ 例：《说散就散》"下/话/怕"

**遥条韵** (ao/iao): 好/笑/老/少/飘  
→ 悠长、感叹、余韵  
→ 适合：怀旧、感慨、温柔的释放  
→ 例：《后来》"好/老/了"

#### 收敛韵（适合主歌、内心戏、细腻情感）

**衣期韵** (i/ü/er): 你/去/雨/离/地  
→ 细腻、私密、内敛  
→ 适合：内心独白、细腻情感、亲密对话  
→ 例：《小幸运》"你/遇/去"

**姑苏韵** (u): 路/哭/住/雾/孤  
→ 低沉、压抑、沉重  
→ 适合：悲伤、孤独、压抑的情绪  
→ 例：《孤独患者》"路/哭/住"

**人辰韵** (en/in/un/ün): 人/心/门/深/真  
→ 内敛、沉思、深沉  
→ 适合：回忆、思考、内心挣扎  
→ 例：《十年》"人/深/认"

#### 中性韵（灵活使用）

**灰堆韵** (ei/ui): 泪/回/美/飞/醉  
→ 适合转折、情绪变化  
→ 既可以悲伤（泪/碎）也可以甜蜜（美/醉）

**由求韵** (ou/iu): 走/手/头/流/久  
→ 流动感、延续感  
→ 适合：时间流逝、离别、思念

**怀来韵** (ai/uai): 来/爱/海/外/白  
→ 开放、期待、向外  
→ 适合：呼唤、等待、希望

### 粤语韵母的情感色彩

#### 开阔韵

**aa 韵** (aa/aai/aau): 花/大/快/开  
→ 最开阔，适合副歌高潮

**ang 韵** (ang): 生/明/情/城  
→ 悠长、大气

**ung 韵** (ung): 中/风/空/红  
→ 深沉、有力

#### 收敛韵

**i 韵** (i): 诗/知/时/思  
→ 细腻、内敛

**ui 韵** (ui): 回/对/泪/醉  
→ 情感细腻、适合内心戏

**ou 韵** (ou): 路/苦/住/雾  
→ 低沉、压抑

### 实战建议：情绪与韵母的匹配

**情绪打开**（从压抑到释放）:
- V1 用收敛韵（i/u/en）→ C 用开阔韵（ang/a/ao）
- 例：主歌"你/去/雨"（收敛）→ 副歌"想/忘/光"（开阔）

**持续压抑**（全曲低沉）:
- 全曲用收敛韵（u/en/in）
- 适合：悲伤、孤独、压抑的主题
- 注意：要慎用，容易让听众感觉"闷"

**持续明亮**（全曲开朗）:
- 全曲用开阔韵（a/ai/ang）
- 适合：励志、欢快、释放的主题

**波动起伏**:
- V1 开阔 → C 收敛 → V2 开阔 → Final C 最开阔
- 制造情绪的反复和层次

### 转韵时机

- Verse → Chorus 可以换韵（情绪转换的信号）
- Verse 1 和 Verse 2 通常同韵
- Bridge 几乎总是换韵（制造"第三幕"感）
- 同一段内不建议频繁换韵（除非刻意制造不安感）

### 押韵质量

**好的押韵**：
- 自然，不为押韵而扭曲语序
- 韵字本身有意义，不是凑数
- 偶尔用"近韵"（韵母接近但不完全相同）增加变化

**坏的押韵**：
- 为了押韵用了不自然的词（"为了押 ang 韵硬用'芬芳'"）
- 每行都押同一个字（"心/心/心"）
- 韵字全是虚词（"的/了/着"）

### 仿写模式的押韵处理

仿写时，分析原曲的押韵方案：
1. 每段押什么韵？
2. 密度如何？（每行/隔行/更松）
3. 哪里转韵？

新词不必押同一个韵母，但应保持相同的密度和转韵节奏。
