# Song Structure Templates

Use this when writing in creation or original mode. Imitation mode follows the source song's structure and doesn't need this file.

## Templates

### Verse-Chorus

```
Verse 1 → Chorus → Verse 2 → Chorus → Outro
```

The most common structure. Use when the chorus carries the emotional weight and the verses set up situations.

- Typical: 4–8 lines per verse, 4–6 lines per chorus.
- Suited to: most pop, mid-tempo emotional songs.

### Verse-Pre-Chorus-Chorus

```
Verse 1 → Pre-Chorus → Chorus → Verse 2 → Pre-Chorus → Chorus → Bridge → Chorus
```

Adds a pre-chorus to build tension. Use when the verses are calm and the chorus needs a runway.

- Pre-chorus: typically 2–4 lines, rising in energy.
- Suited to: ballads with big choruses, anthems.

### AABA (Tin Pan Alley / 老派抒情)

```
A → A → B (bridge) → A
```

Old-school structure. Each A is 8 bars / ~4 lines; the B contrasts. Use when you want a classic, song-form feel.

- Suited to: jazz-influenced pop, retro ballads, some 80s/90s Cantopop.

### Verse-Chorus-Bridge-Chorus

```
Verse 1 → Chorus → Verse 2 → Chorus → Bridge → Chorus (often modulated or held)
```

The standard "modern pop" form. The bridge offers a perspective shift before the final chorus.

- Bridge: 4–6 lines, often a viewpoint or temporal shift.
- Suited to: modern pop ballads, songs that need a third act.

### Through-Composed (叙事/民谣)

No repeating chorus; the song progresses linearly through stanzas, often telling a story.

- Suited to: narrative ballads, folk, story songs.
- Lyrics carry the load — strong imagery and progression matter more than a hook.

## Choosing a structure

| Theme / emotion | Suggested structure |
|---|---|
| Big single emotion, hook-driven | Verse-Chorus or Verse-Pre-Chorus-Chorus |
| Slow build to release | Verse-Pre-Chorus-Chorus |
| Reflective, quiet | AABA or Verse-Chorus |
| Story / narrative | Through-Composed |
| Modern pop with a turn | Verse-Chorus-Bridge-Chorus |
| Imitation mode | Use the source song's structure |

## Rhyme density

- Pop ballads: typically rhyme on every line or every other line in the chorus, looser in verses.
- Cantopop: dense rhyme is common, especially in choruses.
- Folk/narrative: looser rhyme; the storytelling drives the form.

## Line counts

Rough working ranges:

- Verse: 4–8 lines
- Pre-Chorus: 2–4 lines
- Chorus: 4–8 lines (the hook line often repeats)
- Bridge: 4–6 lines
