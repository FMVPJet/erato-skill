# Imagery Library (意象库)

Concrete imagery is what separates human lyrics from AI lyrics. This file provides a curated library of imagery organized by emotion, plus pairing principles to create fresh combinations.

## 意象搭配原则

### 1. 具体 + 抽象

**原理**: 用具体物件承载抽象情感，让情感可触摸。

❌ "思念像风一样"（两个都抽象，空洞）  
✅ "思念是你外套口袋里还有我的手套"（具体物件 + 抽象情感）

❌ "爱情很温暖"（抽象形容）  
✅ "爱情是冬天你递过来的热奶茶"（具体场景）

### 2. 大 + 小（尺度对比）

**原理**: 大小对比制造张力，小意象往往更动人。

❌ "宇宙/星辰/大海"（全是大意象，空洞）  
✅ "宇宙那么大，我只想要你手心的温度"（大小对比）

❌ "整个世界都在下雨"（太大，不真实）  
✅ "你走后，我的世界只剩下窗外的雨声"（缩小到"窗外"）

### 3. 通感（跨感官）

**原理**: 打破感官边界，创造新鲜感受。

✅ "你的声音是蓝色的"（听觉 + 视觉）  
✅ "寂寞的味道"（情感 + 嗅觉）  
✅ "温柔的重量"（触觉 + 抽象）  
✅ "甜蜜的疼痛"（味觉 + 触觉）

### 4. 意外组合（避免陈词滥调）

**原理**: 避开常见搭配，创造惊喜。

❌ "玫瑰 + 爱情"（太常见）  
✅ "空调外机 + 等待"（日常物件 + 情感，新鲜）

❌ "月亮 + 思念"（老套）  
✅ "便利店的灯光 + 思念"（都市感，新鲜）

❌ "眼泪 + 伤心"（直接）  
✅ "妆花了 + 伤心"（更具体，更有画面）

### 5. 动态 > 静态

**原理**: 动作比状态更有画面感。

❌ "我很孤独"（静态状态）  
✅ "我一个人数对面楼的灯，一盏一盏灭掉"（动态过程）

❌ "时间过去了"（抽象）  
✅ "日历一页一页撕掉"（具体动作）

### 6. 细节 > 概括

**原理**: 越具体越动人。

❌ "我们曾经很快乐"（概括）  
✅ "我们曾经在天台吃泡面看日出"（具体场景）

❌ "你的东西还在"（笼统）  
✅ "你的牙刷还在杯子里，毛都炸开了"（细节）

## 按歌手风格选择意象

### 林夕
**偏好**: 时间/玻璃/尘埃/距离/命运/镜子/影子  
**特点**: 抽象哲学类，重隐喻  
**例**: "十年之前我不认识你" / "原来过得很快乐，只我一人未发觉"

### 方文山
**偏好**: 青花瓷/烟雨/江南/书法/古镇/朝代/武侠物件  
**特点**: 古典文化类，画面感强  
**例**: "天青色等烟雨" / "素胚勾勒出青花"

### 黄伟文
**偏好**: 口红/品牌/地铁站名/便利店/商场/化妆品  
**特点**: 都市消费类，现代感  
**例**: "红色高跟鞋" / "在铜锣湾地铁站"

### 李宗盛
**偏好**: 皱纹/白发/旧沙发/账单/中年生活细节  
**特点**: 中年生活类，平实具体  
**例**: "越过山丘才发现无人等候" / "明白了生活"

### 姚谦
**偏好**: 日常小物/窗/光线/安静的场景  
**特点**: 细腻生活类，女性视角  
**例**: "窗外的麻雀" / "安静的午后"

### 周耀辉
**偏好**: 抽象概念/哲学意象/陌生化的日常  
**特点**: 智性诗意类，实验性  
**例**: "时间的灰烬" / "语言的尽头"

## 使用建议

1. **每段至少 2 个具体意象**，避免全是抽象词
2. **主歌和副歌的意象要有对比**（如：主歌用小意象，副歌用大意象）
3. **同一意象不要在一首歌里重复出现**（除非刻意设计的 motif）
4. **优先选择五感可感知的意象**（看得见、听得到、摸得着）
5. **避免"万能意象"**（梦想/远方/星辰大海/心里的光）

## Self-check

写完后检查：
- [ ] 每段有没有至少 2 个具体意象？
- [ ] 意象是否符合歌手风格？
- [ ] 有没有用"万能意象"或陈词滥调？
- [ ] 意象之间有没有新鲜的搭配？
- [ ] 闭上眼睛，能"看到"画面吗？
