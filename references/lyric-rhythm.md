# Lyric Rhythm (歌词节奏感)

Lyrics are not just words — they have rhythm. The way syllables group and pause creates the "flow" of a song. This file guides you in designing rhythmic patterns that match the emotion and enhance singability.

## 音节分组（Phrasing）

中文歌词的节奏由"音节组"决定，不是单个字。同样的字，不同的分组，节奏完全不同。

### 常见分组模式

**2-2 模式**（稳定、对称）
```
我们 / 曾经 / 那么 / 相爱
```
→ 平稳、叙事、理性  
→ 适合：回忆、陈述、平静的叙述

**2-3 模式**（流动、叙事）
```
我们 / 曾经那么 / 相爱
```
→ 前半稳定，后半延展  
→ 适合：情感逐渐展开

**3-2 模式**（强调前半）
```
我们曾经 / 那么 / 相爱
```
→ 前重后轻，强调前半部分  
→ 适合：回忆、强调过去

**单字停顿**（强调、呼吸）
```
我 / 在这里 / 等你
```
→ 每个字都有重量，停顿感强  
→ 适合：强调、呐喊、情绪爆发

**长句流动**（4-5 字组）
```
我用尽全力 / 去追逐你的背影
```
→ 流畅、抒情、绵延  
→ 适合：思念、沉浸、梦境

**混合模式**（长短交替）
```
我用尽全力去追逐你的背影 / 可是 / 够不够
```
→ 长句铺垫 + 短句爆发  
→ 最有张力，最动态

## 节奏与情绪的关系

| 节奏类型 | 情绪效果 | 适用场景 | 例子 |
|---|---|---|---|
| 短促（1-2字组） | 急促、紧张、碎片化 | 焦虑、争吵、心碎 | "走吧 / 算了 / 够了" |
| 均匀（2-2 或 3-3） | 平稳、叙事、理性 | 回忆、陈述、观察 | "我们 / 曾经 / 那么 / 相爱" |
| 长句（4-5字组） | 流畅、抒情、绵延 | 思念、沉浸、梦境 | "我用尽全力 / 去追逐你的背影" |
| 混合（长短交替） | 动态、有张力 | 情绪起伏、对话感 | "我等了很久 / 可是 / 你没来" |

## 副歌的节奏设计

### Hook line 通常是最短的节奏单元

这是制造记忆点的关键技巧：用长句衬托短句，让 hook 突出。

**例子 1**:
```
我用尽全力去追逐你的背影 (长句，10字)
可是 (停顿)
够不够 (短句，hook，3字)
```

**例子 2**:
```
如果你太累 (4字)
及时地道别没罪 (7字)
```
→ 第二句更长，但"如果你太累"因为在前面，反而成为 hook

**例子 3**:
```
我 (1字，最短)
愿意 (2字)
为你 (2字)
```
→ 单字开头，极具冲击力

### 副歌的节奏对比

**主歌 vs 副歌的节奏差异**:
- 主歌：长句、均匀节奏、叙事流动
- 副歌：短句、停顿多、节奏强烈

**例子**:
```
[Verse 1]
我站在这里看着你的背影 / 消失在人群中 (长句，叙事)
想说的话 / 都卡在喉咙里 (均匀)

[Chorus]
走吧 (2字，短促)
算了吧 (3字)
我们 / 到此为止 (2-4，停顿)
```

## 节奏的情感表达

### 低强度情感（1-3）→ 长句、均匀节奏
```
窗外的雨还在下 / 桌上的咖啡冷了
```
→ 平静叙述，没有急促感

### 中强度情感（4-6）→ 混合节奏
```
我想你了 / 可是不敢说 / 怕你 / 已经忘了我
```
→ 长短交替，情感开始波动

### 高强度情感（7-10）→ 短句、碎片化
```
走吧 / 算了吧 / 够了 / 别说了
```
→ 急促、爆发、情绪失控

## 节奏与唱感的关系

### 快歌的节奏要求

**节奏要清晰**:
- 避免过长的音节组（≤3 字一组）
- 多用停顿，给歌手换气空间
- 避免连续的复杂辅音（zh/ch/sh/r）

❌ "我深深地沉浸在这种感觉中"（太长，咬字累）  
✅ "我沉浸 / 在这感觉 / 无法自拔"（分组清晰）

### 慢歌的节奏要求

**节奏可以更自由**:
- 可以用长句（4-5 字组）
- 可以跨小节延续（enjambment）
- 重点是情感的延展，不是节奏的清晰

✅ "我用尽全力去追逐你的背影"（长句，慢歌可以）

### 呼吸点的设置

**规则**: 每 8-12 字必须有一个自然停顿点（逗号、句号、或意义停顿）

❌ "我站在这里看着你的背影消失在人群中然后转身离开"（17字无停顿，唱不了）  
✅ "我站在这里，看着你的背影，消失在人群中"（5+5+5，有停顿）

## 节奏的变化技巧

### 1. 渐变（从长到短）

制造紧迫感、情绪累积：
```
我用尽全力去追逐你的背影 (10字)
可是你越走越远 (6字)
最后只剩下 (5字)
背影 (2字)
```

### 2. 突变（长句 → 短句）

制造冲击、强调：
```
我们曾经说好要一起走到最后 (长句)
可是 (短句，突然刹车)
你走了 (短句，冲击)
```

### 3. 重复节奏（Rhythmic Motif）

在副歌中重复相同的节奏模式，增强记忆：
```
我愿意 (1-2)
为你 (2)
我愿意 (1-2，重复)
为你 (2，重复)
```

### 4. 对话式节奏

一问一答，制造互动感：
```
你还爱我吗？(5字，问)
不知道 (3字，答)
你会回来吗？(5字，问)
不一定 (3字，答)
```

## 在三种模式中的应用

### Imitation 仿写
1. 分析原曲的节奏模式（标注每行的音节分组）
2. 新词保持相同的节奏模式
3. 特别注意 hook line 的位置和长度

### Creation 创作
1. 根据情绪选择节奏类型
   - 平静 → 均匀节奏
   - 爆发 → 短促节奏
   - 思念 → 长句流动
2. 副歌的 hook line 设计为最短单元
3. 主歌和副歌的节奏要有对比

### Original 原创
1. 根据风格描述推断节奏
   - "民谣" → 长句、自由节奏
   - "流行" → 均匀、清晰节奏
   - "摇滚" → 短促、强烈节奏
2. 确保节奏与情感匹配

## Self-check

写完后，大声读一遍（不唱，只读），检查：
- [ ] Hook line 是不是最短的？
- [ ] 节奏是否单调（全是 2-2-2-2）？
- [ ] 长句（≥10 字）是否有停顿点？
- [ ] 情绪高潮处是否用了短促节奏？
- [ ] 主歌和副歌的节奏是否有对比？

如果有任何一项不满足，调整对应行的分组或长度。
