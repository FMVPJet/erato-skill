# Abstract Style Keywords

Use this when the user specifies an abstract style description in original mode (e.g. "忧郁的城市民谣", "复古港乐"). This file maps common abstract descriptors to concrete lyrical features.

## Emotional tone descriptors

### 忧郁 (melancholic)
- Minor-key feel in word choice (暗/冷/空/远)
- Slow pacing, longer lines
- First-person introspection
- Imagery: rain, night, empty rooms, distance, fading light
- Sentence endings: trailing off, unresolved questions

### 热烈 (fervent / passionate)
- Declarative statements, exclamations
- Short punchy lines, repetition for emphasis
- Second-person direct address
- Imagery: fire, sun, collision, heartbeat, running
- High rhetorical density (metaphor, hyperbole)

### 疏离 (detached / alienated)
- Third-person or omniscient viewpoint
- Observational rather than confessional
- Urban imagery: crowds, glass, concrete, transit
- Emotional restraint, understatement
- Sentence endings: flat declarations, no questions

### 温柔 (tender / gentle)
- Soft vocabulary (轻/慢/细/柔)
- Conversational tone, plain language
- Domestic or intimate imagery: hands, breath, small gestures
- Second-person or first-person
- Sentence endings: reassurance, gentle questions

### 怀旧 (nostalgic)
- Past tense or temporal markers (曾经/那时/记得)
- Specific sensory details from memory
- Imagery: old photos, childhood places, faded objects
- Reflective tone, often first-person
- Sentence endings: wistful, "如果" constructions

## Setting descriptors

### 城市 (urban / city)
- Locations: 地铁/霓虹/公寓/便利店/天台/街角
- Themes: isolation in crowds, anonymity, fast pace vs. loneliness
- Modern vocabulary, brand names acceptable
- Imagery: neon, concrete, glass, traffic, late-night scenes

### 乡村 / 民谣 (rural / folk)
- Natural imagery: 田野/河流/山/树/风/土
- Slower narrative pacing, story-driven
- Plainer vocabulary, avoid urban slang
- Themes: roots, simplicity, passage of seasons

### 海边 (seaside / coastal)
- Imagery: 浪/沙/盐/船/灯塔/潮汐
- Themes: distance, waiting, departure, horizon
- Often melancholic or reflective
- Vocabulary: 远/归/漂/岸

## Era / aesthetic descriptors

### 复古 (retro / vintage)
- Classical vocabulary or 80s/90s Cantopop/Mandopop references
- AABA or older song structures
- Imagery tied to the target era (cassette tapes, letters, landline phones for 80s/90s)
- Avoid modern slang or tech references

### 现代 / 当代 (modern / contemporary)
- Current slang acceptable
- Urban themes, digital-age imagery (手机/屏幕/信号)
- Verse-Chorus-Bridge or Verse-Pre-Chorus-Chorus structures
- Faster pacing, shorter lines

## Genre descriptors

### 民谣 (folk / ballad)
- Through-composed or loose structure
- Story-driven, narrative lyrics
- Plain language, minimal metaphor
- Acoustic feel in word choice (avoid electronic/synthetic imagery)

### 流行 (pop)
- Hook-driven, memorable chorus
- Verse-Chorus structure
- Balanced metaphor density (not too abstract, not too plain)
- Themes: love, youth, aspiration

### 摇滚 (rock)
- Declarative, rebellious tone
- Short punchy lines, repetition
- Imagery: 路/夜/自由/燃烧
- High energy vocabulary

## Usage

When the user gives an abstract style like "忧郁的城市民谣":

1. Break it into components: 忧郁 (emotional tone) + 城市 (setting) + 民谣 (genre)
2. Pull concrete features from each section above
3. Combine them: first-person introspection + urban imagery (地铁/霓虹) + through-composed structure + plain language
4. Write with those constraints

If components conflict (e.g. "热烈的民谣" — fervent energy vs. folk's plain restraint), ask the user which takes priority or find the intersection (a protest folk song, perhaps).
